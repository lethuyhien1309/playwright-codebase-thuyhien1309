## 1. Thanh công cụ trên cùng (Admin Bar)

| Thành phần | Mô tả |
| Menu tài khoản: chỉnh sửa hồ sơ, đăng xuất |

## 2. Menu điều hướng bên trái (Sidebar)

- **Dashboard**
  - **Home:** Trang tổng quan quản trị
  - **Updates (4):** Quản lý cập nhật WordPress, plugin, theme
- **Posts:** Quản lý bài viết (thêm, sửa, xóa, danh mục, thẻ)
- **Media:** Thư viện hình ảnh, video, tệp tải lên
- **Pages:** Quản lý các trang tĩnh
- **Comments:** Quản lý, duyệt và trả lời bình luận
- **Appearance:** Quản lý giao diện (theme, menu, widget, tùy biến)
- **Plugins (2):** Cài đặt, kích hoạt và quản lý plugin (có 2 plugin cần cập nhật)
- **Users:** Quản lý tài khoản và phân quyền người dùng
- **Tools:** Công cụ nhập/xuất dữ liệu, kiểm tra tình trạng site
- **Settings:** Cấu hình chung của website (general, writing, reading, permalinks…)
- **miniOrange API Authentication:** Plugin cấu hình xác thực API (bảo mật REST API)
- **Collapse Menu:** Thu gọn/mở rộng thanh menu
